۰۱ / اتصال ذخیره‌شدهHTTPS

ترمینال آمادهٔ باز شدن است

کلیک روی آیکون افزونه همین صفحهٔ ترمینال را باز می‌کند. برای بازگشت به تنظیمات، روی آیکون راست‌کلیک کنید و Options / گزینه‌ها را بزنید. حذف از افزونه، فایل هاست را پاک نمی‌کند.

۰۲ / نصب و ارتقای هاست

از File Manager شروع کن

ابتدا وارد cPanel خودت شو و صفحهٔ Upload را باز نگه دار. سپس نشانی همان صفحه را اینجا وارد کن. افزونه از نشست همان تب استفاده می‌کند و رمز cPanel را دریافت نمی‌کند.

ارتقای همان ترمینال

فایل قبلی خوانده شد. آدرس، رمز و محدودیت IP فعلی حفظ می‌شوند. ابتدا نسخهٔ پشتیبان را روی دستگاهت نگه دار؛ این فایل شامل هش رمز است و باید خصوصی بماند.

دریافت پشتیبان فایل قبلی

رمز در حافظهٔ دائمی افزونه ذخیره نمی‌شود. هر نصب یک فایل PHP با شناسهٔ یکتا می‌سازد و فایل قبلی را بازنویسی نمی‌کند. در صورت نصب دوباره، فایل قبلی را خودت از File Manager حذف کن.

۰۳ / رمز ورود

رمز را روی خود هاست عوض کن

پس از تغییر موفق، تمام ورودهای قبلی به ترمینال باطل می‌شوند. اگر دسترسی نوشتن PHP بسته باشد، رمز قبلی حفظ می‌شود.

۰۴ / نسخه‌ها

به‌روز بمان

نسخهٔ نصب‌شده:

دریافت بستهٔ مرورگر منیادداشت‌های انتشار ↗

پس از دریافت، فایل‌ها را در همان پوشهٔ نصب افزونه جایگزین و در صفحهٔ افزونه‌های مرورگر Reload را بزنید. برای ظاهر تازه و رمز کوتاه روی هاست، از بخش نصب و ارتقا، ترمینال فعلی را هم ارتقا دهید.

بسته‌های دستی Chrome و Edge باید از صفحهٔ افزونه‌ها به‌روز شوند. نصب خودکار نسخه‌ها به انتشار در فروشگاه مرورگر نیاز دارد. Firefox برای نصب دائمی و به‌روزرسانی خودکار، بستهٔ امضاشدهٔ Mozilla می‌خواهد.
